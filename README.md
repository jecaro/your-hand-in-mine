# Explosions in the Sky - Your Hand in Mine

This is a transcription of an adaption of `Your Hand in Mine` by Explosions in 
the Sky for piano. [The original sheet music](./your-hand-in-mine-original.pdf) 
was created by Cleiph.

You can find the latest version on the [releases 
page](https://github.com/jecaro/your-hand-in-mine/releases).
